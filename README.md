# وطن يسكن القلوب 🇸🇦 — النسخة المرتبطة بـ Supabase

هذه النسخة مرتبطة بقاعدة Supabase المشتركة، لذلك المشاركات والعدادات تظهر لجميع الزوار.

## الرفع إلى GitHub
استبدلي الملفات القديمة في جذر مستودع `watan` بهذه الملفات الأربعة:
- index.html
- style.css
- app.js
- README.md

ثم انتظري GitHub Pages قليلًا وأعيدي تحميل الموقع.

## الأمان
الموقع يستخدم Supabase Publishable Key فقط. لا يحتوي على service_role أو secret key أو كلمة مرور قاعدة البيانات.
